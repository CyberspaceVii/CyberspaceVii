# CyberspaceVII

[cyberspace7.org](https://www.cyberspace7.org)

- **[XEvil (WebAssembly)](https://github.com/CyberspaceVii/xevil-wasm)** — XEvil 2.1 beta ported to the browser with WebAssembly and an Xlib-on-SDL2 shim; single-player against the game's AI.
- **[Wheel of Misfortune](https://github.com/CyberspaceVii/wheel-of-misfortune)** — A self-hosted spin-the-wheel party game for two adults (18+), with weighted dare wheels, an in-browser editor, and text-to-speech.
- **[Wheel of Misfortune for Android](https://github.com/CyberspaceVii/wheel-of-misfortune-android)** — The same game as a self-contained APK that works offline, with no server and no internet permission.
- **[deepdownlow](https://github.com/CyberspaceVii/deepdownlow)** — A HackRF One spectrum sweeper with signal ranking, frequency-band identification, FCC license lookups, and JSON export.

## Android devices

[A67L Gen 2](#foxxd-a67l-gen-2) · [A67L Gen 1](#foxxd-a67l-gen-1) · [Pritom Max 10](#pritom-max-10-m10_r01)

Device-specific kernels, KernelSU Next modules, and tools. Each repository has its own requirements, installation instructions, and downloads.

### Foxxd A67L Gen 2

| Project | What it does |
| --- | --- |
| [A67L G2 Kernel](https://github.com/CyberspaceVii/kernel-a67lg2) | Custom GKI kernel with KernelSU Next, SUSFS, and NoMount. |
| [SUSFS Config](https://github.com/CyberspaceVii/susfs-config-a67lg2) | Boot-time SUSFS configuration for reported bootloader state and root hiding. |
| [Bluestone](https://github.com/CyberspaceVii/bluestone-a67lg2) | Blocks Rsota and Google firmware installation; retains available OTA offers for inspection. |
| [Debloat](https://github.com/CyberspaceVii/debloat-a67lg2) | Choose which preinstalled carrier apps and factory tools to remove. |
| [Degoogler](https://github.com/CyberspaceVii/degoogler-a67lg2) | Choose how much Google to keep, from trimming telemetry to preparing for microG. |
| [Hubble Null Corrector](https://github.com/CyberspaceVii/hubble-null-corrector-a67lg2) | Disables the factory Hubble/Canary component through boot-time properties. |
| [Enable Tether](https://github.com/CyberspaceVii/enable-tether-a67lg2) | Enables hotspot sharing through the regular mobile-data APN. |
| [The Artful Dodger](https://github.com/CyberspaceVii/artfuldodger-a67lg2) | Captures screenshots of `FLAG_SECURE` windows while leaving their flags intact. |
| [FM Speaker Enable](https://github.com/CyberspaceVii/fmspeakerenable-a67lg2) | Enables FM radio through the speaker using the internal antenna, without wired headphones. |
| [Bootysplash](https://github.com/CyberspaceVii/bootysplash-a67lg2) | Custom power-on logo, boot animation, and boot sound. |
